# 策略对抗审查

立场：假设策略会失败，任务是找出最可能的失败方式并设计能证伪的实验。不要平衡地"列优缺点"，要给出会让它爆掉的具体情形。

## 流程

1. 用一段话复述策略：信号来源、持有期、股票池、市场、预期收益来源（承担了什么风险、利用了什么错误定价、或只是 beta）。
2. 逐项过下面的攻击面，每项写"如何失效 → 什么数据能证伪 → 需要的实验"。
3. 输出 3 个杀死场景和一份实验清单，给出 go / no-go / 需要补数据。

## 攻击面

### 收益来源
- 拆解成 beta、行业/风格暴露、真正的 alpha；如果去掉基准和行业中性化后所剩无几，直接 no-go。
- 谁在另一边亏钱？说不清对手方的策略通常是数据挖掘。

### 拥挤与衰减
- 同类公开策略（动量、PEAD、政策主题、映射交易）是否已被广泛使用；用成交额分位、融资余额变化、社媒热度做拥挤度检验。
- 信号衰减曲线：延后 1、3、5 天进场收益还剩多少。

### 周期依赖
- 策略在流动性收紧、行业下行、A 股熊市（2018、2022、2024 初）、加密崩盘（2022）会怎样；回测区间若没覆盖这些，注明"未经下行周期检验"。

### 成本与容量
- 成本 ×2 后是否仍为正；ADV 1% 约束下的最大资金规模；A 股小市值股的冲击成本。

### 多重检验
- 试过多少参数/变体才得到这个结果；如果 > 10，要求 Deflated Sharpe。

### 市场专属
- A 股：涨停买不到、跌停卖不掉、停牌、退市风险、政策阶段（吹风/征求意见/正式/细则）反应不同、大股东减持窗口。
- 美股：财报前后 IV 变化、盘后消息 gap、ADR 汇率、PDT 规则（小账户）。
- 期权：卖方策略的尾部（gamma/vega）、被指派与提前行权、bid/ask 宽度吃掉理论收益、保证金在暴跌时的变化。
- 加密：交易所风险、资金费率翻转、清算级联、稳定币脱锚、API 中断。

### LLM 参与的策略
- 模型知识截止日之前的样本会泄漏未来；只认截止日之后的样本。
- 打分是否可校准（说 0.8 置信的事件真的 80% 对吗）；一致性（同一材料重复打分方差）。
- 用 LLM 结论做信号的策略必须能做消融：去掉 LLM 项后收益变化多少。

## 输出模板

```
# <策略> 对抗审查 <日期>
## 策略复述（收益来源一句话）
## 三个杀死场景
1. <场景> — 触发条件 / 预计损失 / 历史上最接近的时期
## 攻击面逐项
| 攻击面 | 失效方式 | 证伪数据 | 实验 |
## 实验清单（按成本排序）
## 结论: go / no-go / 补数据后再议
## 若继续，必须设置的限额（单票、行业、总仓、回撤熔断）
```

## 项目约束

- 输出永远是研究结论，不是交易指令；不给具体买卖价格。
- 需要补的数据按 `qw-pit-data-provider` 的规程立项，不用研究缓存冒充 canonical 数据。
- 实验用现有引擎 `src/quant_workbench/backtest/` 跑，结果走 `qw-backtest-audit`。
